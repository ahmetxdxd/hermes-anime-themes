## ⚡ Installation

**Linux / macOS:**
```bash
git clone https://github.com/ahmetxdxd/hermes-anime-themes.git
cd hermes-anime-themes
./install.sh
```

**Windows:**
```bat
git clone https://github.com/ahmetxdxd/hermes-anime-themes.git
cd hermes-anime-themes
install.bat
```

## 🎮 Usage

Switch skins inside Hermes CLI:
```text
/skin bocchi
```

Or set your default skin in `~/.hermes/config.yaml`:
```yaml
display:
  skin: bocchi
```
